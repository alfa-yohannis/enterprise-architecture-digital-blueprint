# Dokumen Kondisi Saat Ini C2

Dokumen ini menggabungkan model Bab 4 sampai 7. Kondisi teramati, penilaian, dan kandidat solusi ditulis terpisah. Lima masalah terbesar diringkas beserta akibatnya bagi organisasi.

## Cara memakai

1. Tetapkan lingkup, versi artefak, tanggal, dan penanggung jawab.
2. Baca contoh sintetis Medikara, lalu ganti dengan bukti tim yang berizin.
3. Isi satu baris per masalah atau artefak. Bedakan fakta, asumsi, dan target.
4. Uji tiap masalah dengan penelusuran: keluhan, kapabilitas, konsep data, aplikasi, antarmuka, teknologi.

## Susunan dokumen

| Bagian | Bukti utama | Pemeriksaan |
| :-- | :-- | :-- |
| Konteks dan lingkup | Organisasi, periode, sumber, batas data | Sesuai C1 |
| Bisnis (Bab 5) | Capability map, value stream, heatmap | Definisi dan sumber jelas |
| Data (Bab 6) | Konsep informasi, CRUD, aliran data | Pemilik dan klasifikasi konsisten |
| Aplikasi (Bab 7) | Katalog, TIME, matriks kapabilitas | Biaya dan kode dapat ditelusuri |
| Integrasi (Bab 7) | Katalog antarmuka, application cooperation view | Pasangan aktif dan jalur manual tercatat |
| Teknologi (Bab 7) | Lanskap, technology view, utang teknis | Tanggal pemeriksaan dukungan tercatat |
| Temuan | Lima masalah, akibat, pemilik, keterbatasan | Siap diuji pada tinjauan UTS |

## Pemeriksaan sebelum pengumpulan
